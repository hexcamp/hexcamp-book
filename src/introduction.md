# Introduction

This book is a work-in-progress. 

It will soon have some explainer material that describes the project, what it is, what it is for, and why we are making it.  

Additionally, it will contain reference material describing the various components, links to projects we like, as well as guides for operating the software involved.

Much of the documentation that currently exists is in the form of private notes. The goal is to gradually migrate those private notes (and enhance them) into this published book meant for a public audience.
